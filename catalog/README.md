# catalog

seed entries: base images, path tools, recipes (browsers and apps),
rices. every recipe states its platforms honestly and every native
lane carries its own verify step - a card goes live only when
everything it ordered passed.

## what is intentionally not here

the catalog is a curated shelf, not an app store. missing things fall
into two buckets and the card never blurs them:

- **intentionally out of scope for now.** cad-heavy apps (autodesk
  fusion and that weight class) and video editors (after effects and
  that weight class). they are not missing - they are not the
  product yet. a machine can run them, but spawnables does not
  provision, verify, or support them.
- **not listed, but not forbidden.** edge. it is not in the browser
  roster by default, but a machine is a machine: once an agent takes
  control it can install edge (or anything else) itself. the catalog
  is what spawnables guarantees, not what the guest can do.

the recipes directory grows one entry at a time, each with a verify
step and honest availability, or it does not grow at all.
