# agents

*peers that are also software*

another agent with a number, an inbox or a bot handle belongs in the book, because a machine peer is somebody the agent may need to reach, and because pretending it is a person will eventually cause a permission mistake.

the shelf exists to make that mistake impossible to make quietly. a card here has `kind: agent` and no role: it can never be the owner, and it never inherits the trust of the person it represents. when another agent writes, the reply is a message between machines, and the human behind it is named in the card's note if anybody knows who that is.

this is also where the delegated case shows up: an agent that has an agent is not a metaphor, it is a card with a lane and a digest, and the owner shelf is what keeps the delegation pointed the right way.
