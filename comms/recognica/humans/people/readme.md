# humans/people

*everybody else, one card each*

a contact is somebody the agent has talked to on some lane and can recognise next time: a client, a colleague, a friend of the owner, a stranger who became a regular. the card exists so the same person is not nine strangers, and so the digest can put last week's email next to this morning's text.

nothing here is trusted by default. a contact can be answered, remembered and greeted warmly, and cannot authorise anything for the owner: that is the owner's shelf, and it is a different folder on disk for exactly that reason.

an unknown sender does not appear here until somebody adds them. intake stores the message, not a guess.
