# humans

*the people shelf*

two sub-shelves, because "who the agent serves" and "who the agent talks to" are different questions with different consequences.

- [owner](owner/readme.md): the person the agent answers to. exactly one, named rather than inferred.
- [people](people/readme.md): everybody else, from a one-line introduction to a client of two years.

a card moves between these shelves only when somebody moves it. the agent does not promote an inbound sender, and it does not demote its owner because a new handle appeared.
