# the gui mode

the order form at [web/index.html](../../../web/index.html), served by
the [control plane](../../../src/spawnables/server.py). the pickers
render from the real catalogs (os -> distro -> desktop, tools, apps,
services, rice), impossible next steps gray out by the availability
matrix, and nothing is promised before /api/orders/validate passes.

the card is the machine: verbs carry idempotency keys (a double-send
acts once), burn demands the typed name, duplicate clones the manifest
with fresh identity for a one-thing tweak, presets keep named copies.
the gui is one file with no build step and no external fonts.
