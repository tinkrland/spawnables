# the gui mode

gui first, and the gui runs in the browser: the order form at
[web/index.html](../../../web/index.html) is a single file with no
build step, served by the
[control plane](../../../src/spawnables/server.py) - open
http://127.0.0.1:8600 and the whole control surface is there.

the pickers render from the real catalogs (os -> distro -> desktop,
tools, apps, services, rice), impossible next steps gray out by the
availability matrix, and nothing is promised before
/api/orders/validate passes. the card is the machine: verbs carry
idempotency keys (a double-send acts once), burn demands the typed
name, duplicate clones the manifest with fresh identity for a
one-thing tweak, presets keep named copies. no external fonts, ever.
