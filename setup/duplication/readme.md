# duplication and presets

one mechanism, two shapes ([presets.py](../../src/spawnables/presets.py)):

- duplicate: a card's manifest clones verbatim with fresh identity -
  nothing but identity is new - you tweak one thing (ram, distro, apps,
  services) and run. the clone validates like any order, vault refs
  included.
- preset: the same kept copy, named, reusable - order new machines from
  it any time. presets are manifests, not a second schema.

both exist because the order is the machine's dna: replay is already
the primitive, so a copy is just another order.
