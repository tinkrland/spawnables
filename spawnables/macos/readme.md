# the macos lane

apple-silicon host only - by standing rule, macos runs on real
apple-silicon hardware (tenki mac runners, m-series), never emulated
elsewhere. honest limits on the card: no snapshots, no stop/start, so a
macos card offers desktop view and burn only; sizing is fixed
4 vcpu / 8 gb / 80 gb until the backend says otherwise.

this is also the lane that runs ipad-only apps: that story lives in
[../ipad](../ipad/readme.md). machinery:
[runner/lanes/macos](../../runner/lanes/macos).
