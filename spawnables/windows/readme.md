# the windows lane

windows 10 22h2 and 11 24h2 images. honest limits, surfaced on the card:

- exec is ssh-only; there is no snapshot surface, so freeze and
  full-machine export gray out (the card shows why, not just that).
- office is native here and only here; the app availability matrix
  grays it everywhere else.
- the lane is staged pending an iso: the definitions and adapters are
  in, the boot is not run yet.
